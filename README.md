# 🚌 BusRoute+

### Community-Verified Tamil Nadu Bus Finder

BusRoute+ helps users search bus routes, discover stops, report delays, share crowd information, and explore interactive maps.

### 🌐 Live Website
[**Open BusRoute+**](https://busroute-plus-frontend.vercel.app)

### 🔌 Backend API
[**Explore API Documentation**](https://busroute-plus-api.onrender.com/docs)

### 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: SQL

### ✨ Key Features
- Bus route and stop search
- Community delay reporting
- Crowd-level reporting
- Fare information
- Route diversion information
- Interactive map
